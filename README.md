# Super Store Sales Analysis Dashboard (Excel)</br>
## Project Overview</br>
This project presents an interactive Sales Analysis Dashboard built in Microsoft Excel using the Global Superstore dataset. The dashboard provides comprehensive insights into sales performance, profitability, product trends, regional performance, and market distribution through dynamic visualizations and KPI metrics.
The objective of this project is to transform raw transactional data into meaningful business insights that support data-driven decision-making.</br>
